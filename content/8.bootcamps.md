#front-title
Introduction

#front-image
![Codecademy Bootcamps Hub](/images/bootcamps/bootcamps_hub.png)

#front-text
Bootcamps became a top revenue generator for Codecademy, but the system was in dire need of better architecture.

I successfully advocated for and spearheaded a cross-team, multi-month initiative to migrate onto a 2.0 system that was completed in March 2026.

#back-title
Problems with the MVP

#back-image
![Bootcamps Migration Diagram](/images/bootcamps/migration_diagram.png)

#back-text
I created the above diagram to help management understand the problem and my proposed solution.

The original system had been cobbled together from multiple, duplicative data sources which meant it:
- was a highly manual effort to manage
- severely limited feature development

Migrating onto a single source of truth would address these issues.
::

::page{:pageIndex=1 :totalPages=totalPages}
#front-title
New Data Modeling

#front-image
![New Data Modeling Whiteboard](/images/bootcamps/whiteboard.png)

#front-text
For the engineers, I prepared a data modeling whiteboard doc to detail the proposed architecture.

Our 'content service' (CSV4) database would house the main info about bootcamps, but these records also needed to indirectly tie to our user (monolith) and payment service DB models as well.

#back-title
Seamless Management System

#back-image
![Author CMS](/images/bootcamps/author_cms.png)

#back-text
The new 2.0 system leveraged the Codecademy 'Author' tool to manage bootcamp offerings instead of requiring manual marketing page creations.

This saved our ops and marketing teams many hours of tedious manual work per each new bootcamp launch.
::

::page{:pageIndex=2 :totalPages=totalPages}
#front-title
User Manual Documentation

#front-image
![Ops guidebook](/images/bootcamps/ops_guidebook.png)

#front-text
Prior to launch, I coordinated live training sessions to demo the system to ops and marketing teams.

I also prepared and shared out a guidebook with detailed screenshots and all the how-to's for the 2.0 setup so the transition would be smooth.

#back-title
Improved Product Features

#back-image
![Bootcamp Syllabus](/images/bootcamps/unenrolled_syllabus.png)

#back-text
On March 10, 2026 we cut over from the old to the new without any disruption to end users.

The new architecture had allowed us to include feature improvements as well, most notably, fully localized syllabus details to a user's specific timezone.  This replaced clunky, manually curated PDF downloads with limited timezone support.
